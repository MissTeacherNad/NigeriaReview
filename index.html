Present perfect

On l’utilise pour parler d’une évolution passée qui a un résultat visible dans le présent. On ne donne pas de date passée précise.

HAVE / HAS + participe passé
Nollywood has reached new audiences.
Nollywood a atteint de nouveaux publics et le résultat est encore vrai aujourd’hui.
Streaming platforms have transformed distribution.
Le sujet est pluriel, donc on emploie have.

À retenir

I / you / we / they → have
he / she / it → has

Passive voice

Le passif met l’accent sur l’action ou sur ce qui subit l’action. L’auteur de l’action peut être ajouté avec by, mais il n’est pas toujours nécessaire.

BE au temps voulu + participe passé

Passer de l’actif au passif

SujetVerbe actifComplément d’objetVerbe passif

Active: Streaming platforms distribute Nigerian films.

1. Repère le complément d’objet : Nigerian films.
2. Place-le au début : il devient le sujet.
3. Conjugue BE au même temps que le verbe actif.
4. Ajoute le participe passé du verbe : distributed.
5. Ajoute by + agent seulement si cette information est utile.

Passive: Nigerian films are distributed by streaming platforms.

La même phrase à différents temps

TempsActifPassif
Present simpleStreaming platforms distribute Nigerian films.Nigerian films are distributed by streaming platforms.
PreteriteStreaming platforms distributed Nigerian films.Nigerian films were distributed by streaming platforms.
Present perfectStreaming platforms have distributed Nigerian films.Nigerian films have been distributed by streaming platforms.
FutureStreaming platforms will distribute Nigerian films.Nigerian films will be distributed by streaming platforms.

À retenir : on conserve le même temps, mais on le construit sur BE. Le verbe principal reste au participe passé.

Present perfect passive

HAVE / HAS + BEEN + participe passé
Nigerian stories have been made accessible worldwide.

Compound adjectives · Adjectifs composés

Un adjectif composé réunit au moins deux mots pour qualifier un nom de façon plus précise. Placé avant le nom, l’ensemble s’écrit généralement avec un trait d’union.

élément 1 + élément 2 → adjectif composé + nom

1. Une forme en -ing exprime une action active

Le nom qualifié accomplit l’action exprimée par le verbe.

life-saving equipment = equipment which saves lives
long-lasting influence = influence which lasts a long time

2. Le participe passé exprime une action subie ou un résultat

Le nom qualifié est né, produit, tissé, caché ou transformé d’une certaine manière.

Nigerian-born singer = a singer who was born in Nigeria
Nollywood-produced series = a series which was produced by Nollywood
hand-woven fabric = fabric which was woven by hand
well-hidden reference = a reference which is well hidden

3. Un adjectif ou un nom peut préciser le sens

world-famous artist = an artist who is famous worldwide
high-tech creation = a creation using advanced technology

Le trait d’union

Avant le nom : a world-famous artist.
Après le verbe be, certains groupes s’écrivent séparément : the artist is world famous.

Méthode : repère le nom qualifié, cherche la relation entre les deux éléments, puis demande-toi si le sens est actif (-ing) ou passif/résultatif (participe passé).
